# Project Charter

## Core Problem
Manual software delivery work across research, planning, development, review, and testing is slow and difficult for non-technical users to supervise. The project should automate that lifecycle into a structured, manager-led workflow.

## End User
Non-technical users who want to describe an idea and have the toolkit guide AI agents through a disciplined software delivery process.

## Constraints
- Budget-sensitive implementation using the existing local toolkit and CLI/MCP patterns.
- Production-ready behavior for the selected scope.
- No existing external code, data, APIs, or services to integrate.

## Definition of Done
The toolkit provides a production-ready workflow path that turns a user idea into auditable research, planning, coding, review, and test artifacts, with validation gates and clear final reporting.
